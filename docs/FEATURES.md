# 方舟 ARK 功能介绍

断网、断电、没有医生的时候，手机里剩下的东西就是全部家当。方舟 ARK 把这些装进一个安卓 App：**本地 AI、离线资料、地图海图、求生工具**，全程不联网，也不上传任何东西。

## 一、本地 AI 问答

### 1. 模型就跑在手机上

- Google **Gemma 4 E2B**（2.4 GB），用 LiteRT-LM 运行时，**GPU 加速**；显卡跑不动时自动退 CPU。
- 也能换更聪明的 **E4B**（3.4 GB），慢一些、占内存更多，在「资料」页下载即可切换。
- GPU 激活精度固定为 **FLOAT32**：默认精度下模型会把数字抄错（实测 6–11 处），改用 FLOAT32 后降到 0，代价是约 14% 的能耗——本项目认为剂量数字不能错，值得。
- 上下文上限 4096 token，贪心解码（topK=1、温度 0.1），关闭“思考”输出：少生成一个字就少耗一份电，答案也更稳定。

### 2. 先检索，再作答

- **两路检索**：一路是英文关键词全文检索（SQLite FTS5，bm25 排序），一路是**语义检索**（EmbeddingGemma 270M，256 维 int8 向量）。两路各取前 50 段，用 RRF 融合排前 4 段送进模型。
- 资料包的索引和向量都是英文的（英文手册的检索质量高得多），所以中文问题先由小模型改写成 3–6 个英文关键词，再把**中文译文**交给模型——检索走英文，阅读走中文。
- 没装语义模型也能用，只走关键词那一路；两样都不装也能直接搜原文。

### 3. 每句都有出处，数字有人管

- 检索到的每一段编号 `[1]…[4]`，模型被要求在用到的句子后标号，点号看原文。
- **数字核对**：回答里每个数字都会去出处原文和你的问题里找，找不到的标红并提示「可能是抄错或换算，用药和剂量请点出处核对原文」。
- 资料里真没有相关内容时，模型会说「资料中没有提到」，不硬编。
- 提示词里明确禁止用资料以外的知识补充数字、剂量或药名。
- 觉得有用的回答可加书签，连同出处原文一起保存，断网时也能翻。

### 4. 可靠性上的几处补救

- 资料太长时小模型偶尔会“忘掉问题”，回一句「请提供您的问题」——这时自动把问题挪到资料前面重问一次。
- 贪心解码偶尔会重复同一行，检测到就截断，省时间也省电。
- 逐字输出最多每秒刷新 8 次界面，最后一个字一定刷出去；开始出字后不再显示转圈，减少 GPU 抢用。
- 模型空闲 10 分钟自动释放内存（重新加载约 9 秒、40 焦耳，所以不会更省电，只是为了不长期占内存）。
- 算数工具：内置一个认单位的计算器（能算 `3e8 m/s / 146 MHz / 4 to cm`）。108 题盲评里换用它的提示词收益不明显、危险回答反而多，因此**默认关闭**，代码保留。

### 5. 不该拒答的时候不拒答

这是一台断网断电时的求生工具。武器、自卫、野兽与野味处理、危险品之类的问题，它照常按资料回答，不做安全说教式拒答。

### 6. 速度与耗电（小米 12S Ultra 实测）

| 指标 | 数值 |
|---|---|
| 一个问题耗时 | 20–35 秒（含检索；首次要加载模型，更慢） |
| 输出速度 | 18–21 token/秒 |
| 首字时间 | 2–4 秒 |
| 每次问答整机耗电 | 约 90–120 焦耳（约占满电 0.2%） |
| 每 token 耗电 | 约 0.2 焦耳（DEFAULT 与 FLOAT32 精度基本相同） |

## 二、离线资料

- 内置约 2.4 万段、106 MB 核心资料：急救医学、饮水、食物、野外求生、无线电、机械维修、能源。
- 中文显示，可一键切换英文原文对照；不装 AI 也能直接搜原文，几乎不耗电。
- 25 张急救步骤卡（心肺复苏、出血、窒息、烧伤、蛇咬、一氧化碳中毒等），一步一屏，零耗电，另附勘误表。
- 任何书、PDF、网页都能自己做成资料包导入。

## 三、地图与海图

- 内置全球卫星底图 + 矢量概略图，GPS 定位不需要网络。
- 11 个区域详图按需下载（中国、日韩、东南亚、欧洲、北美、南美、非洲、俄罗斯中亚、南亚中东、澳新、全球 8 级）。
- 海图：全球水深着色、等深线、59 万个航标灯塔（含灯质）。
- 航点、轨迹记录、沿轨迹返回、导出 GPX；没有 GPS 时可用交会定位。

## 四、方向与定位

- 指南针有真北/磁北切换；靠近车辆、钢筋、磁吸壳导致磁干扰时，用陀螺保持方向并提示。
- 磁干扰严重时用「天体定向」：相机对准太阳、月亮或亮星，按算出的方位校准，之后 30 分钟不依赖磁力计。
- 气压海拔、3 小时气压趋势和简易天气预报；日出日落、晨昏光和距天黑时间。

## 五、不联网也能互通消息

- **蓝牙短消息**：不配对、不联网，几十米内直接发送，三台以上自动接力（最多 3 跳）。
- **超声传信**：17–19.5 kHz 近超声，人耳听不见，一台播一台收，适合隔着门或墙传一句 SOS。
- **蓝牙求救信标**：广播自己的位置和状态，附近装了方舟的手机会在地图上看到「求救 / 平安」和距离。
- **警报声**：定时鸣响，用于被埋、迷路时让救援听到。

## 六、其他工具

闪光灯 SOS 与摩尔斯信号、屏幕信号灯、CPR 节拍器、止血带计时、饮水消毒剂量、物资计算（人数 × 天数 → 水和热量）、应急信息卡、单位换算。

## 七、省电与可用性

- 纯黑界面，息屏停传感器，只在需要时推理。
- 12S Ultra 实测：一个问题 15–25 秒，整机耗电约 90–120 焦耳（约占满电的 0.2%）。
- 低端机可用 CPU 后端，慢一些但能跑。
- 支持把安装包、资料包、地图通过手机热点分享给身边的人，对方用浏览器下载。

## 开始用

1. 从 [Releases](https://github.com/Yu-DaTouX/ARK/releases) 下载 APK 安装（约 200 MB，含核心资料和全球地图）。
2. 打开「资料」页，下载模型：Gemma 4 E2B（2.4 GB，必需）和语义检索模型 EmbeddingGemma（165 MB，推荐）。
3. 回到「问答」页直接提问；其他功能在「工具」和「地图」页。
